# ERP Shell and Colour System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เปลี่ยนโครงหน้าจอเป็นแบบ ERP ที่เพิ่มระบบใหม่ได้จากทะเบียนระบบ และเปลี่ยนสีทั้งโปรแกรมเป็นชุดสีน้ำเงินองค์กร โดยไม่แตะกฎการทำงาน

**Architecture:** ทะเบียนระบบเป็นข้อมูลล้วนใน `src/modules/` ที่ทั้งฝั่งเซิร์ฟเวอร์และเบราว์เซอร์ import ได้ โครงหน้าจอใน `src/components/shell/` เป็น client component ที่อ่านทะเบียนกับ `usePathname()` แล้ววาดแถบระบบ เมนู และแถบบน ส่วน `src/app/(app)/layout.tsx` ส่งเฉพาะบทบาท ข้อมูลผู้ใช้ และตัวเลขจำนวนงานลงไป หน้าของระบบขนส่งย้ายไปอยู่ใต้ `/transport` หน้าผู้ดูแลอยู่ใต้ `/admin` และ `next.config.ts` ส่งต่อที่อยู่เดิม สีทั้งหมดเป็นตัวแปรใน `globals.css`

**Tech Stack:** Next.js 16.4.5 (App Router, Turbopack), React 19.3, Tailwind 4, shadcn บน Base UI, lucide-react, Vitest 5

**Spec:** `docs/superpowers/specs/2026-11-15-erp-shell-design.md` ผู้ลงมือต้องอ่านคู่กับแผนนี้ ภาพต้นแบบอยู่ที่ `docs/superpowers/specs/assets/2026-11-15-erp-shell-mockup.html` (โทน `navy`)

```ts
// src/test/source-files.ts
import { readdirSync } from "node:fs";
import { join } from "node:path";

/** Every hand-written .ts/.tsx file under src, without tests and generated code. */
export function sourceFiles(dir = "src"): string[] {
  return readdirSync(dir, { withFileTypes: true }).flatMap((entry) => {
    const path = join(dir, entry.name);
    if (entry.isDirectory()) return entry.name === "generated" || entry.name === "test" ? [] : sourceFiles(path);
    return /\.tsx?$/.test(entry.name) && !entry.name.includes(".test.") ? [path] : [];
  });
}

// src/test/route-paths.test.ts
import { readFileSync } from "node:fs";
import { expect, test } from "vitest";
import { sourceFiles } from "./source-files";

test("no source file points at a pre-ERP address", () => {
  const legacy = /["'`]\/(jobs|queues|masters|settings)(?![\w-])/;
  const hits = sourceFiles().flatMap((file) =>
    readFileSync(file, "utf8").split("\n").flatMap((line, i) => (legacy.test(line) ? [`${file}:${i + 1}`] : [])),
  );
  expect(hits).toEqual([]);
});
```

```ts
import { readFileSync } from "node:fs";
import { expect, test } from "vitest";

const root = readFileSync("src/app/globals.css", "utf8").match(/:root\s*\{([^}]*)\}/)![1];
const vars = Object.fromEntries([...root.matchAll(/--([\w-]+):\s*(#[0-9a-fA-F]{6})\s*;/g)].map((m) => [m[1], m[2]]));

function luminance(hex: string) {
  const [r, g, b] = [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16) / 255)
    .map((v) => (v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4));
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}
function contrast(a: string, b: string) {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}

const tones = ["neutral", "info", "progress", "warning", "success", "pending", "done", "danger"];
const bands = ["status", "money", "weight"];

  ["primary", "card"], ["primary-foreground", "primary"], ["secondary-foreground", "secondary"],

  ["rail-foreground", "rail"], ["rail-active-foreground", "rail-active"],
  ["sidebar-foreground", "sidebar"], ["sidebar-accent-foreground", "sidebar-accent"],
```

- เมนู (`bg-sidebar`, ขอบขวา): แสดงเมื่อ `resolveLocation(pathname, role).module` ไม่เป็น `null` หัวเมนูมีคำว่า `ระบบ` ตัวเล็กและ `name`; รายการจาก `visibleSections` สูง 38px; รายการ active พื้น `bg-sidebar-accent` ตัวอักษร `text-sidebar-accent-foreground` และ `shadow-[inset_3px_0_0_var(--primary)]`; ป้ายตัวเลขชิดขวาแสดงเฉพาะเมื่อ `counts[module.id]?.[countKey]` เป็นตัวเลข จัดรูปด้วย `toLocaleString("th-TH")` ค่ามากกว่าศูนย์ใช้พื้น `bg-sidebar-accent` ศูนย์ใช้ `bg-muted text-muted-foreground`
- แถบบน: ปุ่มไอคอนด้านซ้าย (`aria-label` `ย่อเมนู`/`ขยายเมนู` บนจอกว้าง และ `เปิดเมนู` บนจอแคบ); ตำแหน่งหน้า `<name> › <label>` หรือ `หน้าแรก` เมื่อ `pathname === "/"`; ขวาคือ `displayName` บรรทัดรอง `username · roleLabel` (ซ่อนบรรทัดรองเมื่อแคบกว่า 640px ตัดชื่อยาวด้วย `truncate`) และ `<form action={logoutAction}>` ที่มีปุ่มไอคอน `LogOut` `aria-label="ออกจากระบบ"`

- จอแคบกว่า 768px: แถบระบบและเมนูซ่อน ปุ่มในแถบบนเปิดแผงจากซ้ายที่มีทั้งสองส่วน แผงปิดเมื่อแตะลิงก์ แตะพื้นหลัง (`bg-foreground/40`) หรือกด Esc

- สีเมื่อชี้เปลี่ยนใน 150 ถึง 250ms ไม่มีการขยับตำแหน่ง ทุกลิงก์และปุ่มมีวงโฟกัส `focus-visible:ring-3 focus-visible:ring-ring/30`
