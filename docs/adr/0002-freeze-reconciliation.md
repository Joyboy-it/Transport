# บันทึกผลเทียบน้ำหนักตอนบันทึกน้ำหนัก และไม่คำนวณใหม่เมื่อเปลี่ยนเกณฑ์

ผลการเทียบน้ำหนัก (ตรงกัน อยู่ในเกณฑ์ เกินเกณฑ์ รอตรวจสอบ) ใช้ตัดสินว่าใบงานต้องให้ผู้อนุมัติดูหรือไม่ และต่อไปจะใช้คำนวณเงิน ถ้าคำนวณสดจากเกณฑ์ปัจจุบัน การแก้เกณฑ์ครั้งเดียวจะเปลี่ยนผลของใบงานเก่าที่ยืนยันหรือจ่ายไปแล้วย้อนหลัง จึงคำนวณผลทุกครั้งที่บันทึกน้ำหนัก แล้วเก็บผล ส่วนต่าง และเกณฑ์ที่ใช้ลงในใบงานนั้น การเปลี่ยนเกณฑ์มีผลกับการบันทึกน้ำหนักครั้งถัดไปเท่านั้น

## Consequences

- ใบงานแสดงเกณฑ์ที่ใช้ตัดสิน ซึ่งอาจต่างจากค่าในหน้าตั้งค่า
- ถ้าต้องการตัดสินใบงานเก่าใหม่ด้วยเกณฑ์ใหม่ ต้องแก้หรือบันทึกน้ำหนักซ้ำ (หลังยืนยันน้ำหนักต้องมีเหตุผล)
