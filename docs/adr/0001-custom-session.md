# ใช้ session ของระบบเองแทน Auth.js

ระบบรันใน LAN ด้วยบัญชีที่ผู้ดูแลระบบสร้างให้เท่านั้น ไม่มี OAuth ไม่มีอีเมล และต้องปิดบัญชีหรือรีเซ็ตรหัสผ่านแล้วให้ผู้ใช้หลุดทันที จึงเก็บ session ในตาราง `Session` ของ PostgreSQL (cookie เก็บ token สุ่ม ฐานข้อมูลเก็บ HMAC ของ token) แทนการใช้ Auth.js ซึ่งออกแบบมาเพื่อ provider ภายนอก และโหมด credentials ของมันบังคับใช้ JWT ที่เพิกถอนรายตัวไม่ได้

## Consequences

- ปิดบัญชีหรือรีเซ็ตรหัสผ่านจะลบ session ของผู้ใช้นั้นทั้งหมด
- cookie ตั้ง `secure` เฉพาะเมื่อ `COOKIE_SECURE=true` เพราะ LAN ระยะแรกใช้ HTTP ถ้าเปิด HTTPS ภายหลังต้องตั้งค่านี้
- ถ้าวันหนึ่งต้องเชื่อม SSO ขององค์กร ต้องเพิ่ม flow เองหรือย้ายไปไลบรารี
